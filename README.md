# Jaso NFC

한국어 · [English](README.en.md)

분리되거나 깨진 한글 파일명을 정리하세요. Jaso NFC는 선택한 폴더와 새로 들어오는 파일의 이름을 자동으로 정리합니다. 바뀔 이름을 미리 확인하고, 한 창에서 현재 활동·폴더·변경 기록·설정을 관리하세요.

[제품 소개](https://garlicvread.github.io/jaso-nfc/) · [사용 설명서](docs/usage.md)

## 1. 설치 파일 열기

1. 다운로드한 DMG를 열고 `Install Jaso NFC.app`을 더블클릭하세요.
2. `설치`를 누르고 완료될 때까지 창을 열어 두세요.
3. 완료 화면에서 `설치 파일 유지` 또는 `설치 파일 휴지통 이동`을 선택하세요. 휴지통 이동 대상은 원본 DMG입니다.
4. 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.

앱은 응용 프로그램 폴더에 설치됩니다. 실행이 차단되면 [앱 실행 허용 안내](docs/usage.md#실행이-차단될-때)를 따라 주세요.

## 2. 폴더와 바뀔 이름 확인하기

메뉴 막대에서 `Jaso NFC 열기…`를 선택한 뒤 `폴더`로 이동하세요. 다운로드 폴더를 고르고 `파일명 미리보기`에서 현재 이름과 정리 후 이름을 비교해 보세요. 필요한 폴더를 추가하거나 제외할 수 있습니다.

이미 사용 중이라면 저장된 폴더 목록을 먼저 확인하세요. 외장 드라이브는 `드라이브`에서 선택하고, 각 드라이브를 다시 연결했을 때 자동으로 이어갈지 직접 시작할지 정할 수 있습니다.

사용을 마친 드라이브는 상세 창의 `목록에서 제거`로 정리 대상에서 뺄 수 있습니다. `.ghost-alice` 같은 숨김 폴더는 기본 검사에서 제외하며, 필요한 폴더는 직접 선택해 추가할 수 있습니다.

## 3. 자동 정리 시작하기

미리보기 결과를 확인한 뒤 `자동 정리 시작`을 누르세요. 선택한 폴더와 이후 들어오는 파일을 계속 확인합니다. 앱을 일시 정지해 두었다면 준비됐을 때 `재개`를 선택하세요.

`상태`에서 오늘 정리한 이름과 확인이 필요한 항목을 보고, `활동 보기`로 현재 경로와 진행 상황을 살펴보세요.

## 한 창에서 사용하는 기능

| 하고 싶은 일 | 선택할 탭 또는 항목 |
| --- | --- |
| 현재 상태와 오늘의 변경 확인 | `상태` |
| 지금 확인하는 경로와 진행 상황 보기 | `활동` · 필요하면 `별도 창으로 보기` |
| 폴더·제외 항목·외장 드라이브 관리 | `폴더` |
| 변경한 이름 검색과 원래 이름 복원 | `변경 기록` |
| 로그인 시 실행, 언어와 테마 선택 | `설정` |
| 접근 권한과 저장 공간 확인 | `설정` → `상세 설정` |
| 정리를 잠시 미루기 / 이어가기 | 메뉴의 `일시 정지` / `재개` |

`활동`에서는 최근 작업과 현재 대기 중인 항목을 확인하세요. 작업이 멈췄을 때는 클라우드 보관, 접근 권한 등 확인된 이유를 표시하고, 이후 검사가 성공하면 해당 활동에 완료 결과를 표시합니다. 완료한 이름 변경은 `변경 기록`에 보관됩니다. 기록을 선택하면 원래 이름과 변경한 이름, 위치를 확인하고 해당 항목만 되돌릴 수 있습니다.

정리한 이름은 변경 이력을 한 번 남깁니다. 같은 파일을 다시 검사할 때는 진행 정보만 갱신하고, 같은 문제로 재시도할 때는 활동 목록의 기존 항목을 갱신합니다. 최근 변경 기록은 정해진 용량 안에서 보관하고 오래된 기록부터 자동으로 정리합니다. `설정` → `상세 설정` → `저장 공간 사용량…`에서 파일 목록, 변경 기록, 로그와 앱 버전이 차지하는 공간을 확인하세요.

창을 닫으면 백그라운드에서 정리를 계속합니다. 작업까지 종료하려면 메뉴에서 `Jaso NFC 종료`를 선택하세요. 다음에 사용할 때는 응용 프로그램 폴더에서 앱을 여세요.

## 도움이 필요할 때

- 폴더 접근 권한이 필요하면 `설정` → `상세 설정` → `전체 디스크 접근 권한 열기…`에서 Jaso NFC를 허용한 뒤 `정리 작업 다시 시작`을 선택하세요.
- 클라우드 항목에 대기가 표시되면 `활동`이나 `상태`에서 경로와 이유를 확인하고 Finder와 동기화 앱에서 연결·다운로드 상태를 살펴보세요.
- 디스크 여유 공간은 `설정` → `상세 설정` → `저장 공간 사용량…`에서 확인하세요.
