# Jaso NFC

한국어 · [English](README.en.md)

분리된 한글 파일명을 정리하세요. Jaso NFC는 선택한 폴더와 새로 들어오는 파일의 이름을 자동으로 정리하고, 메뉴 막대에서 처리 상태와 확인이 필요한 항목을 보여 줍니다.

[제품 소개](https://garlicvread.github.io/jaso-nfc/) · [사용 설명서](docs/usage.md)

## 다운로드

[다운로드](https://github.com/garlicvread/jaso-nfc/releases/download/v0.1.0/Jaso-NFC-0.1.0-arm64-local.dmg)

0.1.0 · Apple Silicon Mac(M1 이후) · macOS 13 이상 · 무료 / [MIT 라이선스](LICENSE)

앱을 설치하고 다운로드 폴더의 한글 파일명부터 정리해 보세요.

## 1. 설치 파일 열기

1. 다운로드한 DMG를 열고 `Install Jaso NFC.app`을 더블클릭하세요.
2. `설치`를 누르고 완료될 때까지 창을 열어 두세요.
3. 완료 화면에서 `설치 파일 유지` 또는 `설치 파일 휴지통 이동`을 선택하세요. 휴지통 이동 대상은 원본 DMG입니다.
4. 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.

앱은 응용 프로그램 폴더에 설치됩니다. 실행이 차단되면 [앱 실행 허용 안내](docs/usage.md#실행이-차단될-때)를 따라 주세요.

## 2. 변경할 파일 확인하기

메뉴 막대의 Jaso NFC → `정리할 폴더…`를 여세요. 다운로드 폴더를 선택하고 `파일명 미리보기`를 눌러 현재 이름과 정리 후 이름을 확인하세요. 필요한 폴더를 더 추가하거나 목록에서 뺄 수 있습니다.

이미 사용 중이라면 저장된 폴더 목록을 먼저 확인하세요. [폴더 선택과 제외 설정](docs/usage.md#change-folders)에서 자세한 방법을 안내합니다.

## 3. 자동 정리 시작하기

미리보기 결과를 확인한 뒤 `자동 정리 시작`을 누르세요. 선택한 폴더를 정리하고 이후 들어오는 파일도 계속 확인합니다. 메뉴의 `상태 보기…`에서 현재 활동과 처리할 항목을 확인할 수 있습니다.

## 매일 사용하는 기능

| 하고 싶은 일 | 선택할 항목 |
| --- | --- |
| 활동과 문제 파일 확인 | `상태 보기…` |
| 정리를 잠시 미루기 / 이어가기 | `일시정지` / `계속 진행` |
| 정리할 폴더 변경 | `정리할 폴더…` |
| 설정한 범위의 폴더 재확인 | `상태 보기…` → `전체 감시 영역 다시 확인` |
| 로그인 시 실행, 언어, 테마 선택 | `설정…` |
| 중지한 정리 작업 시작 | `작업 시작` |

창을 닫으면 백그라운드에서 정리를 계속합니다. 작업까지 종료하려면 `Jaso NFC 종료`를 선택하세요. 다음에 사용할 때는 앱을 열고 `작업 시작`을 누르세요. 로그인할 때 자동으로 시작할지는 설정의 `로그인할 때 실행`에서 선택할 수 있습니다.

## 문제를 해결하려면

- 폴더 접근 권한이 필요하면 `설정…` → `전체 디스크 접근 권한 열기…`에서 설치된 Jaso NFC를 추가해 허용한 뒤, 상태 창의 `작업 다시 시작`을 선택하세요.
- 클라우드 폴더에 재시도가 표시되면 상태 창의 경로를 Finder에서 열어 보고, 동기화 앱의 로그인과 연결을 확인하세요.
- 이름 충돌이나 잠긴 항목이 표시되면 `파일별 상태`에서 해당 파일의 원인과 확인 방법을 따라 주세요.
