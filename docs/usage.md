# Jaso NFC 사용 설명서

한국어 · [English](usage.en.md) · [다운로드](../README.md)

Jaso NFC 0.2.0으로 다운로드 폴더의 한글 파일명부터 정리하고 필요한 폴더를 추가해 보세요. 폴더 선택, 이름 미리보기, 자동 정리와 원래 이름 복원을 차례로 안내합니다.

## 설치와 실행

1. Apple Silicon Mac(M1 이후), macOS 13 이상에서 [설치 파일을 다운로드](https://github.com/garlicvread/jaso-nfc/releases/download/v0.2.0/Jaso-NFC-0.2.0-arm64-local.dmg)하세요.
2. DMG를 열고 `Install Jaso NFC.app`을 더블클릭한 뒤 `설치`를 누르세요.
3. 완료 화면에서 `설치 파일 유지` 또는 `설치 파일 휴지통 이동`을 선택하세요. 휴지통 이동 대상은 원본 DMG입니다. 버튼이 비활성화되어 있으면 Finder에서 해당 파일을 정리하세요.
4. 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.
5. 응용 프로그램 폴더에서 Jaso NFC를 여세요. 메뉴 막대의 `Jaso NFC 열기…`로 작업공간을 다시 열 수 있습니다.

처음에는 다운로드 폴더를 제안합니다. 업데이트한 경우 저장된 폴더와 제외 설정을 먼저 확인해 주세요.

### 실행이 차단될 때

다운로드한 파일의 출처를 확인한 뒤 [Apple의 앱 실행 허용 안내](https://support.apple.com/ko-kr/102445)를 따라 주세요.

1. 경고에 표시된 앱을 한 번 열어 보세요.
2. `시스템 설정 → 개인정보 보호 및 보안`에서 해당 앱의 `확인 없이 열기`를 선택하세요.
3. 다시 표시되는 창에서 `열기`를 선택하세요.

`확인 없이 열기`가 없거나 손상 메시지가 나오면 DMG를 다시 다운로드하거나 지원팀에 문의해 주세요. 설치 프로그램과 설치된 Jaso NFC 중 경고에 표시된 앱을 기준으로 확인하세요.

## 분리되거나 깨진 한글 이름 정리하기

Jaso NFC는 파일과 폴더의 분리된 한글 이름을 NFC 형식으로 맞춥니다. 일반 파일의 이름에는 문자 인코딩이 잘못 읽혀 깨진 한글을 복원하는 기능도 적용합니다. 폴더를 선택하고 `파일명 미리보기`를 누르면 두 종류의 변경을 함께 확인할 수 있습니다.

| 현재 이름 | 정리 후 이름 |
| --- | --- |
| `ㅂㅗㄱㅗㅅㅓ.pdf` · 자음·모음이 따로 저장된 이름 | `보고서.pdf` |
| `µµÀüÀÇ IRÆ÷½ºÅÍ-ÃÖÁ¾º».pdf` | `도전의 IR포스터-최종본.pdf` |

파일명 인코딩 복구는 UTF-8 또는 CP949로 저장했던 문자를 Latin-1·Windows-1252로 잘못 읽은 경우 중, 원래 바이트와 한글 이름을 손실 없이 되찾을 수 있는 경우에 적용합니다. CP949 파일명은 한국어 파일명에 쓰이는 단어와 문자 손상 흔적도 함께 확인합니다. 복원 근거가 충분하지 않거나 여러 해석이 가능한 이름은 현재 이름을 유지합니다. 이미 `?`나 `�`로 대체되어 원래 문자 정보가 사라진 부분은 정확한 원래 이름을 확인한 뒤 Finder에서 수정해 주세요.

자동 정리를 시작하면 같은 규칙으로 새 이름도 확인합니다. 완료한 변경은 `변경 기록`에서 검색하고 되돌릴 수 있습니다. 파일명 복원 결과와 별개로, 문서 본문의 글자가 깨졌다면 해당 문서를 여는 앱에서 인코딩을 확인해 주세요.

## 작업공간 둘러보기

`상태`, `활동`, `폴더`, `변경 기록`, `설정`은 같은 창 안에서 전환됩니다.

| 탭 | 여기서 할 수 있는 일 |
| --- | --- |
| `상태` | 현재 상태, 오늘 정리한 이름, 최근 변경과 확인이 필요한 항목을 살펴보세요. |
| `활동` | 현재 경로와 실제 처리 수치를 확인하고 최근 작업을 따라가세요. |
| `폴더` | 폴더·제외 항목·외장 드라이브를 선택하고 이름을 미리 확인하세요. |
| `변경 기록` | 이름이나 폴더로 검색하고 날짜·결과를 고른 뒤 한 항목의 원래 이름을 복원하세요. |
| `설정` | 언어, 테마와 로그인 실행을 선택하고 `상세 설정`에서 권한·저장 공간을 확인하세요. |

## 정리할 폴더 선택하기

1. `폴더`의 `선택한 폴더` 목록을 확인하세요.
2. `폴더 추가…`로 원하는 폴더를 추가하세요. 뺄 폴더는 선택한 뒤 `선택 항목 제거`를 누르세요.
3. 일부 하위 폴더를 제외하려면 `제외할 폴더`를 펼치고 `제외 폴더 추가…`를 선택하세요.
4. `파일명 미리보기`에서 현재 이름과 정리 후 이름을 비교하세요.
5. 준비되면 `자동 정리 시작`을 누르세요.

폴더나 제외 항목을 바꿨다면 미리보기를 다시 실행하세요. `미리보기 취소`로 확인을 중단할 수 있습니다. 시간 제한이나 접근 오류가 표시되면 안내된 위치를 확인하고 필요한 폴더를 따로 미리보세요.

`설정 저장`은 폴더 선택과 모드를 저장하면서 현재 실행·일시 정지 상태를 유지합니다. `자동 정리 시작`은 자동 모드를 켜고 선택을 저장합니다. 이미 일시 정지한 앱은 메뉴의 `재개`를 선택하면 정리를 이어갑니다.

`모든 사용자 파일 영역`은 계정 홈 폴더, 공용 폴더와 클라우드 문서 폴더를 찾습니다. 특정 위치만 정리하려면 `선택한 폴더`에 추가하세요. 저장한 제외 규칙은 두 방식 모두에 적용됩니다.

`.ghost-alice`, `.venv`처럼 이름이 점으로 시작하는 숨김 폴더는 기본 검사에서 제외합니다. 해당 폴더를 정리하려면 `선택한 폴더`에 직접 추가하세요. 직접 추가한 폴더 안에서도 하위 숨김 폴더는 제외 규칙을 따릅니다. 선택한 폴더를 모두 제거한 상태도 저장할 수 있으며, 다음 폴더를 추가하면 정리를 시작할 수 있습니다.

### 외장 드라이브와 다시 연결하기

`드라이브`에서 정리 대상과 연결 상태를 확인하세요. `연결된 드라이브 추가…`로 드라이브를 추가하고 `설정 저장`을 누르세요. 방금 연결했다면 `드라이브 새로고침`을 선택하세요.

`모든 사용자 파일 영역`에서는 `기존 드라이브 포함` 또는 `직접 선택`으로 관리 방식을 고를 수 있습니다. `선택한 드라이브 제거`로 정리 대상에서 뺀 드라이브는 나중에 다시 추가할 수 있습니다.

드라이브를 선택하고 `선택한 드라이브 관리…`를 열어 `이 드라이브를 다시 연결하면` 항목을 설정하세요.

| 선택 | 다시 연결했을 때 |
| --- | --- |
| `기본값 · 자동으로 이어서 정리` / `자동으로 이어서 정리` | 앱이 실행 중이면 정리를 이어갑니다. 앱을 일시 정지한 상태는 유지합니다. |
| `직접 시작` | 연결할 때마다 드라이브 상세의 `이 드라이브 시작`을 눌러 준비하세요. 앱 전체가 일시 정지 중이면 `재개`도 선택하세요. |

재연결 방식을 고른 뒤 상세 창의 `저장`을 누르세요. 함께 수정 중인 폴더의 미리보기가 필요하면, 미리보기 후 `설정 저장`을 눌러 드라이브 설정까지 적용하세요. 직접 시작은 선택한 드라이브의 현재 연결에 적용됩니다. 이름이 같은 다른 드라이브는 따로 선택해 주세요.

사용을 마친 드라이브는 연결이 해제된 상태에서도 상세 창의 `목록에서 제거`로 제거할 수 있습니다. 다른 폴더 변경이 없으면 바로 저장됩니다. 함께 수정 중인 폴더의 미리보기가 필요하면, 미리보기 후 `설정 저장`을 눌러 드라이브 제거까지 적용하세요. 저장한 드라이브 제외 설정은 다시 연결한 뒤에도 유지됩니다. `선택한 폴더` 방식에서는 해당 드라이브에 있는 선택 폴더도 함께 목록에서 제거됩니다.

## 상태와 활동 확인하기

`상태`의 `활동 보기`를 누르면 현재 확인하는 폴더나 파일의 경로를 볼 수 있습니다. `오늘 이름을 정리한 파일`은 Mac의 날짜를 기준으로 완료한 이름 변경을 세며, 나중에 원래 이름으로 되돌려도 그날 변경했던 사실은 유지됩니다.

`활동`에서는 현재 단계, 경로, 이번 실행의 검사 완료 수와 이름 변경 수, 마지막 진행 시각을 확인할 수 있습니다. 전체 수가 확인된 작업에는 진행 막대를 표시합니다. 폴더 정보를 기다리는 동안에는 대기 중인 경로와 마지막 진행 시각을 살펴보세요.

- `전체`, `이름 변경`, `오류·대기`로 최근 작업을 골라 보세요. `오류·대기`에서는 완료 결과가 기록된 항목을 제외합니다.
- `새 활동 따라가기`를 켜면 새 항목으로 이동합니다. 이전 내용을 읽을 때는 꺼 두세요.
- `별도 창으로 보기`로 활동 창을 따로 열어 둘 수 있습니다.

`최근 활동`에서 작업 결과와 당시의 오류 사유를 확인하세요. 클라우드 보관, 접근 권한, 응답 지연 등 기록된 이유를 표시합니다. 같은 검사가 이후 성공하면 기존 활동에 완료 결과를 표시하며, 항목을 열어 당시 사유와 완료 시각을 확인할 수 있습니다. `현재 대기 항목`에서는 지금 처리를 기다리는 파일과 폴더를 확인하세요.

최근 활동은 최대 200개를 표시하며 오래된 항목부터 화면 목록에서 빠집니다. 정리된 파일을 다시 확인할 때는 현재 경로와 검사 수를 갱신합니다. 같은 문제로 재시도할 때는 기존 활동 항목의 횟수와 시각을 갱신합니다. 최근에 완료한 이름 변경은 `변경 기록`에서 확인하세요. 현재 작업 정보를 받지 못했다면 `새로고침`으로 연결을 확인하세요.

## 일시 정지와 종료

메뉴의 `일시 정지`로 자동 정리를 미루고, `재개`로 이어가세요. 일시 정지 상태는 앱을 다시 열어도 유지됩니다. 그동안 감지한 변경 사항은 정리를 재개하면 처리합니다.

창을 닫거나 앱을 가리면 백그라운드 작업을 계속합니다. 앱과 작업을 함께 종료하려면 `Jaso NFC 종료`를 선택하세요. 다음에 사용할 때는 응용 프로그램 폴더에서 앱을 열고, 상태 화면에 시작 버튼이 표시되면 선택하세요.

`설정` → `로그인할 때 실행`으로 다음 로그인 때 앱을 시작할지 선택할 수 있습니다.

## 변경 기록 검색과 원래 이름 복원

최근 변경 기록은 용량 기준으로 보관하며 오래된 기록부터 자동으로 정리합니다. 보관 중인 항목은 아래 절차로 되돌릴 수 있습니다. 처리 중인 복구에 필요한 기록은 별도로 유지합니다.

1. `변경 기록`에서 파일 이름이나 폴더를 검색하세요.
2. 필요하면 `날짜`를 켜서 날짜를 고르고, `모든 결과`, `이름 변경`, `되돌림`으로 결과를 좁히세요.
3. 기록을 선택해 `원래 이름`, `변경한 이름`, `위치`, `완료 시각`을 확인하세요. `이전`과 `다음`으로 50개씩 이동할 수 있습니다.
4. `원래 이름으로 되돌리기`를 누르고 확인 안내를 읽으세요.
5. 복원할 수 있는 항목이면 `되돌리기`를 선택하고 완료 메시지를 기다리세요.

요청이 접수된 뒤에는 기존 백그라운드 작업이 해당 항목을 처리합니다. 대기 메시지가 표시되면 결과를 기다려 주세요. 앱 전체가 일시 정지 중이어도 직접 요청한 되돌리기는 처리할 수 있습니다.

파일이 이동·교체되었거나 원래 이름을 다른 항목이 사용 중이면 이유를 표시합니다. 이후의 관련 이름 변경이나 확인이 필요한 클라우드 항목도 함께 점검합니다. 복구 대기 안내가 계속되면 기록을 보관하고 지원팀에 문의하세요.

복원한 항목은 같은 위치와 파일 식별 정보가 유지되는 동안 원래 이름을 유지합니다. 파일 내용 복원은 사용 중인 백업에서 진행하세요. 여러 기록을 함께 다루는 작업은 [고급 복구 안내](installation.md#recovery)를 참고하세요.

정지된 아이콘을 쓰려면 `메뉴 막대 아이콘 애니메이션`을 끄거나 macOS의 동작 줄이기를 켜세요. Command-쉼표로 설정을 열고, Command-더하기·빼기·0으로 콘텐츠 크기를 조절할 수 있습니다.

`상세 설정`에는 `폴더 다시 확인`, `정리 작업 다시 시작`, `진단 정보 복사`, 접근 권한과 `저장 공간 사용량…`이 있습니다. 폴더 재확인은 저장한 범위와 제외 규칙을 따릅니다.

자세한 사용 순서는 `설정` 아래의 `사용 설명서 열기…`에서 다시 확인하세요. 선택한 앱 언어에 맞는 설명서가 열립니다.

### 저장 공간 확인하기

`설정` → `상세 설정` → `저장 공간 사용량…`에서 Jaso 데이터 용량과 데이터가 저장된 디스크의 여유 공간을 확인하세요. Jaso 데이터에는 파일 목록, 변경 기록과 진단 로그가 포함됩니다.

여유 공간이 1 GiB 미만이거나 디스크의 5% 미만이면 안내를 표시합니다. 256 MiB 미만에서는 새 이름 변경을 보류하고 진행 중이던 복구를 마칠 수 있도록 합니다. `저장공간 설정 열기`로 macOS에서 불필요한 파일을 정리한 뒤 작업을 이어가세요. 변경 기록은 복구에 사용할 수 있도록 보관합니다. 확인할 수 없는 용량은 `확인할 수 없음`으로 표시합니다.

## 권한과 문제 해결

| 상황 | 확인 방법 |
| --- | --- |
| 보호된 폴더 접근 불가 | `설정` → `상세 설정` → `전체 디스크 접근 권한 열기…`에서 `+`로 `/Applications/Jaso NFC.app`을 추가해 허용하세요. Finder의 앱을 목록으로 끌어 넣어도 됩니다. 이후 `정리 작업 다시 시작`을 선택하세요. |
| 백그라운드 실행 차단 | `설정` → `로그인 항목 열기…`에서 Jaso NFC의 백그라운드 실행을 허용하세요. |
| 클라우드 항목 대기 | `활동`에서 경로와 이유를 확인하세요. Finder에서 해당 위치를 열고 동기화 앱의 로그인·연결 상태를 확인하세요. 다운로드가 필요하다고 표시되면 Finder에서 항목을 다운로드하세요. |
| 외장 드라이브 대기 | 드라이브를 연결하고 `폴더` → `드라이브`에서 연결 상태와 재연결 방식을 확인하세요. 직접 시작으로 설정했다면 `이 드라이브 시작`을 선택하세요. |
| 이름 충돌·잠긴 항목 | `상태`의 `확인이 필요한 항목`을 선택하고 Finder에서 위치, 잠금, 공유 및 사용 권한을 확인하세요. |
| 예상한 이름이 정리되지 않음 | 자동 모드, 일시 정지 상태, 선택한 폴더와 제외 규칙을 확인하세요. 깨진 이름의 복원 조건은 [파일명 복원 안내](#filename-repair)를 확인하세요. 직접 입력한 `ㅎㅏㄴ` 같은 호환 자모는 NFC 정규화의 대상에서 제외됩니다. |
| 저장 공간 부족 | `설정` → `상세 설정` → `저장 공간 사용량…`에서 데이터가 저장된 디스크를 확인하세요. |

Jaso NFC는 현재 로그인한 계정의 접근 권한으로 작업합니다. 시스템 설정의 항목 이름은 macOS 버전에 따라 조금 다를 수 있습니다. [자세한 권한 안내](installation.md#permissions)를 참고하세요.

## 변경 범위와 안전성

Jaso NFC는 파일과 폴더 이름을 NFC 형식으로 맞추고, 일반 파일에는 [복원 조건에 맞는 파일명 인코딩 복구](#filename-repair)도 적용합니다. 폴더와 심볼릭 링크 항목의 이름은 NFC 형식으로 정리합니다. 선택한 최상위 폴더 안의 항목을 처리하며 최상위 폴더 이름, 볼륨 이름과 심볼릭 링크의 대상은 처리 범위에서 제외됩니다.

자동 제외 항목은 `.git`, AppleDouble 보조 파일(`._*`), 앱 자체의 상태·로그 경로와 다음 패키지의 내부입니다: `.app`, `.photoslibrary`, `.musiclibrary`, `.tvlibrary`, `.aplibrary`, `.framework`. 이 밖에 제외할 폴더는 `폴더`의 `제외 폴더 추가…`로 지정하세요.

`모든 사용자 파일 영역`은 홈 Library 내부, 휴지통과 인식된 시스템 관리 영역을 제외하고 클라우드 문서 폴더를 따로 찾습니다. 저장된 제외 규칙도 적용됩니다.

이름 충돌이 확인되면 항목을 보류하고 상태에 표시합니다. exFAT 등 일부 파일 시스템에서는 다른 앱이 같은 대상 이름을 동시에 만들 경우 덮어쓰기 위험이 있습니다. 이런 위치에서는 다른 앱의 동시 이름 변경을 피하고 [파일 시스템별 처리 한계](architecture.md#mutation-and-recovery)를 확인하세요.

처리 설정, 파일 목록과 변경 기록은 기본적으로 `~/Library/Application Support/jaso-nfc`에 저장됩니다. 언어·테마·콘텐츠 크기는 macOS 환경설정에 저장됩니다. 클라우드 폴더의 이름 변경은 동기화 앱의 설정에 따라 동기화될 수 있습니다.

## 업데이트와 제거

업데이트할 때는 같은 계정에서 새 DMG의 설치 프로그램을 실행하세요. 저장된 폴더와 설정, 변경 기록을 이어서 사용하며, 설치 후 `상태`와 `폴더`에서 확인할 수 있습니다.

제거하려면 `로그인할 때 실행`을 끄고 `Jaso NFC 종료`를 선택한 뒤 [제거 절차](installation.md#uninstall)에 따라 백그라운드 실행 등록을 정리하세요. 응용 프로그램 폴더의 Jaso NFC를 휴지통으로 옮기면 됩니다. 설정과 변경 기록은 재설치나 복구에 활용할 수 있도록 남겨 둡니다.

원래 파일명으로 되돌리고 싶다면 앱을 제거하기 전에 `변경 기록`에서 진행하세요.
