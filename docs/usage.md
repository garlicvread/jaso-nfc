# Jaso NFC 사용 설명서

한국어 · [English](usage.en.md) · [다운로드](../README.md)

Jaso NFC로 다운로드 폴더의 한글 파일명을 정리하고, 필요한 폴더를 추가해 보세요. 이 설명서는 0.1.0의 설치, 폴더 선택, 미리보기와 자동 정리, 문제 해결을 안내합니다.

## 설치와 실행

1. Apple Silicon Mac(M1 이후), macOS 13 이상에서 [설치 파일을 다운로드](https://github.com/garlicvread/jaso-nfc/releases/download/v0.1.0/Jaso-NFC-0.1.0-arm64-local.dmg)하세요.
2. 받은 DMG를 열고 `Install Jaso NFC.app`을 더블클릭한 뒤 `설치`를 누르세요.
3. 설치가 완료되면 `설치 파일 유지` 또는 `설치 파일 휴지통 이동`을 선택하세요. 휴지통 이동 대상은 원본 DMG입니다. 버튼이 비활성화되어 있으면 Finder에서 해당 파일을 정리하세요.
4. 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.
5. 메뉴 막대의 Jaso NFC 아이콘을 눌러 `정리할 폴더…`를 여세요. 다음부터는 응용 프로그램 폴더에서 앱을 실행할 수 있습니다.

처음에는 다운로드 폴더를 정리 대상으로 제안합니다. 업데이트한 경우에는 저장된 폴더와 제외 설정을 이어서 사용하므로 목록을 먼저 확인해 주세요.

### 실행이 차단될 때

다운로드한 파일의 출처를 확인한 뒤 [Apple의 앱 실행 허용 안내](https://support.apple.com/ko-kr/102445)를 따라 주세요.

1. 경고에 표시된 앱을 한 번 열어 보세요.
2. `시스템 설정 → 개인정보 보호 및 보안`으로 이동해 해당 앱의 `확인 없이 열기`를 선택하세요.
3. 다시 표시되는 창에서 `열기`를 선택하세요.

`확인 없이 열기`가 없거나 손상 메시지가 나오면 DMG를 다시 다운로드하거나 지원팀에 문의해 주세요. 설치 프로그램과 설치된 Jaso NFC 중 경고에 표시된 앱을 기준으로 확인하세요.

## 앱에서 시작하기

### 정리할 폴더 고르기

메뉴 또는 설정에서 `정리할 폴더…`를 여세요. `선택한 폴더` 목록을 확인하고 `폴더 추가…`로 원하는 폴더를 추가하세요. 목록에서 뺄 폴더는 선택한 뒤 `선택 항목 제거`를 누르세요.

### 변경할 파일 확인하기

`파일명 미리보기`를 눌러 현재 이름과 정리 후 이름을 비교하세요. 폴더를 바꾸거나 제외 항목을 추가했다면 미리보기를 다시 실행하세요. 확인을 중단하려면 `미리보기 취소`를 누르세요.

미리보기는 일정 시간 동안 확인한 이름을 보여 줍니다. 시간 제한 안내가 나오면 결과를 살펴보고, 더 자세히 확인할 폴더를 선택해 다시 미리보세요.

접근할 수 없는 위치가 표시되면 해당 폴더의 권한이나 연결을 확인하세요. 접근 가능한 폴더부터 정리를 시작할 수 있으며, 미리보기의 오류 안내에서 아직 확인하지 못한 위치를 살펴볼 수 있습니다.

### 자동 정리 시작하기

결과를 확인한 뒤 `자동 정리 시작`을 누르세요. 선택한 폴더와 설정을 저장하고 자동 정리를 시작합니다. 이전에 일시정지해 두었어도 이 버튼을 누르면 정리를 이어갑니다.

메뉴의 `상태 보기…`에서 현재 활동을 확인하세요. 선택한 폴더에 이후 들어오는 파일도 계속 처리합니다. 정리를 잠시 미루려면 메뉴에서 `일시정지`를 선택하세요.

<a id="change-folders"></a>

## 정리할 폴더 선택하기

`정리할 폴더…`에서 폴더 목록과 제외 설정을 함께 관리할 수 있습니다.

| 하고 싶은 일 | 사용 방법 |
| --- | --- |
| 폴더 추가 | `폴더 추가…`를 누르고 정리할 폴더를 선택하세요. |
| 폴더 제거 | 목록에서 폴더를 고른 뒤 `선택 항목 제거`를 누르세요. |
| 일부 폴더 제외 | `제외할 폴더`를 펼친 뒤 `제외 폴더 추가…`로 정리에서 뺄 폴더를 지정하세요. |
| 바뀔 이름 확인 | `파일명 미리보기`를 눌러 현재 이름과 정리 후 이름을 비교하세요. |
| 설정 저장 | `설정 저장`으로 폴더 설정을 적용하세요. 현재 실행·일시정지 상태는 유지합니다. |
| 저장하고 정리 시작 | `자동 정리 시작`을 누르세요. 설정을 저장하고 정리를 시작하거나 이어갑니다. |

처음에는 다운로드 폴더처럼 확인하기 쉬운 폴더에서 시작해 보세요. 기존에 사용 중이라면 저장된 폴더 전체를 확인한 뒤 필요한 폴더를 추가하거나 제거하세요.

`모든 사용자 파일 영역`을 선택하면 계정 홈 폴더, 공용 폴더, 클라우드 문서 폴더와 연결된 외장 볼륨을 자동으로 찾습니다. 나중에 연결되거나 발견된 위치와 제외 영역 밖의 숨김 사용자 파일까지 범위가 넓어질 수 있습니다. 특정 폴더만 정리하려면 `선택한 폴더`를 사용하세요. 두 방식 모두 저장된 제외 설정을 적용합니다.

## 평소 사용하는 메뉴

| 하고 싶은 일 | 사용 방법 |
| --- | --- |
| 처리 상황 확인 | `상태 보기…`에서 활동, 정리 대상 위치, 문제 파일을 확인하세요. |
| 정리를 잠시 미루기 | `일시정지`를 선택하세요. 그동안 발생한 변경 사항은 기록해 둡니다. |
| 미뤄 둔 정리 이어가기 | `계속 진행`을 선택하세요. 일시정지 상태는 앱을 다시 열어도 유지됩니다. |
| 중지한 작업 시작 | `작업 시작`을 선택하세요. |
| 정리할 폴더 변경 | `정리할 폴더…`에서 폴더와 제외 목록을 수정하세요. |
| 설정한 폴더 다시 확인 | `상태 보기…` → `전체 감시 영역 다시 확인`을 누르세요. |
| 앱과 작업 종료 | `Jaso NFC 종료`를 선택하세요. 작업 중지를 확인한 뒤 종료합니다. |

폴더 재확인은 현재 미리보기·자동 정리 설정과 제외 규칙을 따릅니다. 작업이 일시정지되어 있으면 `계속 진행`을, 중지되어 있으면 `작업 시작`을 먼저 선택하세요. 새 감시 폴더를 지정할 때는 [폴더 설정 화면](#change-folders)을 사용하세요.

창을 닫거나 앱을 가리면 백그라운드에서 작업을 이어갑니다. 앱은 Dock에도 표시됩니다. 종료 후 다시 사용하려면 응용 프로그램에서 Jaso NFC를 열고 `작업 시작`을 누르세요. 종료 오류가 표시되면 상태를 확인하고 작업 중지를 다시 시도하세요.

`설정…`의 `로그인할 때 실행`을 켜면 다음 로그인 때 앱과 정리 작업을 시작합니다. 지금 실행 중인 작업은 `일시정지`, `백그라운드 작업 중지`, `종료`로 제어하세요. 다음 로그인 때도 중지 상태를 유지하려면 `로그인할 때 실행`을 꺼 주세요.

## 상태와 설정

`상태 보기…`를 열면 현재 활동과 정리 대상 위치가 표시됩니다. 창이 보이는 동안 5초마다 갱신하며 `새로고침`으로 직접 확인할 수도 있습니다.

| 표시된 상태 | 다음에 할 일 |
| --- | --- |
| `미리보기 모드` | 폴더와 이름을 살펴보는 중입니다. 자동 정리를 시작하려면 `정리할 폴더…`에서 `자동 정리 시작`을 선택하세요. |
| `최초 인덱싱 중` | 폴더 안의 파일 목록을 만드는 중입니다. 처음 발견하는 폴더가 많으면 시간이 걸릴 수 있으니 기다려 주세요. |
| `변경 사항 감지 중` | 처음 확인을 마치고 새 파일과 변경 사항을 기다리고 있습니다. |
| `일시정지됨` / `중지됨` | 정리를 이어가려면 `계속 진행` / `작업 시작`을 선택하세요. |
| `일부 항목 재시도 대기` | `파일별 상태`에서 해당 항목의 원인과 다음 시도 시각을 확인하세요. |
| `접근할 수 없는 위치 확인 필요` | 표시된 경로를 Finder에서 열고 연결이나 접근 권한을 확인하세요. |
| `복구 대기 중` | 미완료 이름 변경이 기록되어 있습니다. 계속 표시되면 기록을 보존하고 지원팀에 문의하세요. |

`인덱스 항목`은 확인해 둔 파일·폴더·링크 수이고, `대기 폴더`는 처리할 폴더 작업 수입니다. `이름 변경 재시도`는 다시 시도할 항목 수입니다. 아직 발견 중인 폴더가 있으면 숫자가 늘어날 수 있으므로 현재 활동 메시지와 함께 확인하세요.

`파일별 상태`에는 파일명, 경로, 기록된 원인과 다음 조치가 표시됩니다. `Finder에서 확인`으로 해당 위치를 열 수 있습니다. 이름 변경 재시도와 폴더 재시도를 각각 최대 8개 보여 주며 전체 대기 수도 함께 표시합니다. 재시도 시각부터 작업 순서에 따라 다시 처리합니다. 이름 변경 실패는 처음 15분 뒤부터 재시도하며 반복 실패 시 간격이 최대 하루까지 늘어납니다.

상태 창 아래에서 `작업 다시 시작`, `백그라운드 작업 중지`, `전체 감시 영역 다시 확인`을 사용할 수 있습니다. `복구 기록 폴더 열기`는 Finder에서 이름 변경 기록을 열고, `진단 정보 복사`는 지원 요청에 사용할 현재 상태를 복사합니다. 공유할 때는 개인 파일명과 경로를 지워 주세요.

`설정…`에서 한국어·영어·시스템 언어를 선택하면 메뉴와 창에 바로 적용됩니다. 기본 아이콘 테마는 `책 속의 명조`입니다. `단정한 고딕`과 해당 글꼴이 준비된 Mac의 `한 획의 궁서`도 선택할 수 있습니다.

| 단정한 고딕 | 책 속의 명조 | 한 획의 궁서 |
| --- | --- | --- |
| ![고딕 테마 미리보기](assets/gothic.gif) | ![명조 테마 미리보기](assets/myungjo.gif) | ![궁서 테마 미리보기](assets/gungseo.gif) |

확대된 테마 미리보기입니다. 아이콘은 12초 주기로 한글이 합쳐지는 모습을 보여 줍니다. 정지된 아이콘을 쓰려면 애니메이션을 끄거나 macOS의 동작 줄이기를 켜세요. 처리 상황은 상태 창에서 확인하세요.

Command-쉼표로 설정을 열 수 있습니다. Command-더하기 또는 Command-등호, Command-빼기, Command-0으로 상태·폴더 설정·앱 설정 창의 글자와 콘텐츠 크기를 80–200% 범위에서 조절하세요. 선택한 크기는 다음 실행에도 적용됩니다.

## 권한과 문제 해결

| 상황 | 확인 방법 |
| --- | --- |
| 보호된 폴더 접근 불가 | `설정…` → `전체 디스크 접근 권한 열기…`에서 `+`로 `/Applications/Jaso NFC.app`을 추가해 허용하세요. 추가가 되지 않으면 Finder의 앱을 목록으로 끌어 넣으세요. 이후 상태 창에서 `작업 다시 시작`을 선택하세요. |
| 백그라운드 실행 차단 | `설정…` → `로그인 항목 열기…`에서 Jaso NFC의 백그라운드 실행을 허용하세요. |
| `/Applications` 설치 권한 오류 | 앱을 설치할 권한이 있는 계정을 사용하거나 Mac 관리자에게 문의하세요. |
| 클라우드 폴더 시간 초과·접근 불가 | Finder에서 해당 경로를 열어 보세요. 동기화 앱 실행 상태와 해당 계정의 로그인·연결을 확인하세요. 연결을 복구하면 예약된 재시도를 기다리거나 감시 영역을 다시 확인하세요. |
| 외장 드라이브 접근 불가 | 드라이브를 연결하고 Finder에서 열리는지 확인하세요. 저장된 작업은 연결이 복구되면 이어서 처리할 수 있습니다. |
| 이름 충돌 | `파일별 상태`에서 원래 이름과 대상 위치를 확인하고, Finder에서 충돌한 두 항목을 구분해 정리하세요. |
| 잠긴 항목·읽기 전용 위치 | Finder의 정보 가져오기에서 잠금과 공유 및 사용 권한을 확인하세요. 읽기 전용 디스크라면 쓰기 가능한 위치의 사본을 사용하세요. |
| 예상한 이름이 정리되지 않음 | 미리보기·일시정지·중지 상태와 설정한 폴더, 제외 규칙을 확인하세요. `ㅎㅏㄴ`처럼 직접 입력한 호환 자모는 이 정규화의 대상에서 제외됩니다. |

Jaso NFC는 현재 로그인한 계정의 접근 권한으로 작업합니다. 다른 계정 소유의 파일은 해당 계정의 공유 권한도 확인해 주세요. 시스템 설정의 항목 이름은 macOS 버전에 따라 조금 다를 수 있습니다. [자세한 권한 안내](installation.md#permissions)를 참고하세요.

## 변경 범위와 안전성

Jaso NFC는 분해된 한글처럼 같은 글자를 다른 문자 조합으로 저장한 파일명과 폴더 이름을 NFC 형식으로 맞춥니다. 선택한 최상위 폴더 안의 항목을 처리하며 최상위 폴더 이름, 볼륨 이름과 심볼릭 링크의 대상은 처리 범위에서 제외됩니다.

자동 제외 항목은 `.git`, AppleDouble 보조 파일(`._*`), 앱 자체의 상태·로그 경로와 다음 패키지의 내부입니다: `.app`, `.photoslibrary`, `.musiclibrary`, `.tvlibrary`, `.aplibrary`, `.framework`. 이 밖에 정리에서 뺄 폴더는 `정리할 폴더…`의 `제외 폴더 추가…`로 지정하세요.

`모든 사용자 파일 영역`은 홈 Library 내부, 휴지통과 인식된 시스템 관리 영역을 제외하고 클라우드 문서 폴더를 따로 찾습니다. Google Drive 제공자 최상위의 `.tmp`는 관리 영역으로 제외하며, 내 드라이브나 공유 드라이브 안의 같은 이름 폴더는 정리 대상이 될 수 있습니다. 실제 처리에는 저장된 제외 규칙도 적용됩니다.

이름 충돌이 확인되면 해당 항목을 보류하고 상태에 표시합니다. exFAT 등 일부 파일 시스템에서는 대상 확인과 이름 변경 사이에 다른 앱이 같은 대상 이름을 만들 경우 그 대상을 덮어쓸 수 있습니다. 이런 위치에서는 다른 앱의 동시 이름 변경을 피하고 [파일 시스템별 처리 한계](architecture.md#mutation-and-recovery)를 확인하세요.

처리 설정, 파일 목록과 이름 변경 기록은 기본적으로 `~/Library/Application Support/jaso-nfc`에 저장됩니다. 언어·테마·콘텐츠 크기는 macOS 환경설정에 저장됩니다. 클라우드 폴더의 이름 변경은 사용 중인 동기화 앱의 설정에 따라 동기화될 수 있습니다.

## 기록된 이름 변경 되돌리기

상태 창에서 `복구 기록 폴더 열기`를 선택하면 이름 변경 기록을 확인할 수 있습니다. 이전 이름으로 되돌리려면 다음 순서로 준비하세요.

1. 설정의 `로그인할 때 실행`을 꺼 주세요.
2. 상태 창에서 `백그라운드 작업 중지`를 선택하세요.
3. [고급 복구 안내](installation.md#recovery)에 따라 사용할 변경 기록을 확인하고 되돌리기를 진행하세요.

되돌리기는 선택한 기록과 압축 보관 이력 전체를 대상으로 합니다. 기록에 있는 원본 파일을 확인할 수 있어야 하며, 이후 이동·삭제·교체된 파일이나 exFAT에서 식별 정보가 바뀐 항목은 실패할 수 있습니다. 파일 내용 복원은 사용 중인 백업에서 진행하세요.

이전 이름을 유지하는 동안 작업을 중지해 두세요. 다시 시작하면 정규화 대상 이름을 다시 처리합니다. 복구 기록과 미완료 작업 기록을 보존하고, `복구 대기 중` 상태가 계속되면 지원팀에 문의해 주세요.

## 업데이트와 제거

업데이트할 때는 같은 계정에서 새 DMG의 설치 프로그램을 실행하세요. 저장된 폴더, 변경 설정, 로그인 실행 선택과 복구 기록을 이어서 사용하며 설치 직후 새 작업을 시작합니다. `상태 보기…`에서 정리 대상과 현재 활동을 확인해 주세요.

앱을 제거하려면 [제거 절차](installation.md#uninstall)에 따라 백그라운드 실행 등록을 먼저 정리한 뒤, 응용 프로그램 폴더의 Jaso NFC를 휴지통으로 옮기세요. 설정과 복구 기록은 재설치나 복구에 활용할 수 있도록 남겨 둡니다.

이전 파일명으로 되돌리고 싶다면 앱을 제거하기 전에 위의 되돌리기 절차를 진행하세요.
