01단계

설치 파일 열기

다운로드한 .dmg를 열고 Install Jaso NFC.app을 더블클릭한 뒤 ‘설치’를 누르세요.

완료되면 원본 DMG를 유지하거나 휴지통으로 옮기세요. 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.

02단계

폴더와 이름 확인하기

메뉴 막대에서 ‘Jaso NFC 열기…’를 선택한 뒤 ‘폴더’로 이동하세요. ‘파일명 미리보기’로 현재 이름과 정리 후 이름을 비교해 보세요.

다운로드 폴더부터 시작하고, 필요한 폴더와 외장 드라이브를 추가하세요.

03단계

자동 정리 시작하기

결과를 확인한 뒤 ‘자동 정리 시작’을 누르세요. 선택한 폴더와 새로 들어오는 파일을 계속 확인합니다.

일시 정지해 두었다면 ‘재개’를 선택하세요. ‘상태’와 ‘활동’에서 진행 상황을 볼 수 있습니다.

폴더와 드라이브

정리할 곳을 고르세요.

‘폴더’에서 폴더 목록과 제외 항목을 관리하세요. 드라이브별로 다시 연결했을 때 자동으로 이어갈지 직접 시작할지도 선택할 수 있습니다.

바뀔 이름을 먼저 확인하세요.

미리보기에서 현재 이름과 정리 후 이름을 나란히 확인할 수 있습니다. 접근할 수 없는 위치가 표시되면 안내에 따라 권한이나 연결을 확인하세요.

‘설정 저장’은 현재 실행·일시 정지 상태를 유지합니다. 준비됐을 때 메뉴에서 ‘재개’를 선택하세요.

보호된 폴더의 권한은 ‘설정’ → ‘상세 설정’ → ‘전체 디스크 접근 권한 열기…’에서 허용하세요. 응용 프로그램 폴더의 Jaso NFC를 추가하고 ‘정리 작업 다시 시작’을 선택하세요.

매일 쓰는 방법

확인할 일은
한 창에서.

메뉴 막대의 ‘Jaso NFC 열기…’로 돌아오세요. 다섯 탭에서 진행 상황을 살펴보고 정리할 위치와 이전 이름을 관리할 수 있습니다.

  • 상태현재 상태와 오늘 정리한 이름, 최근 변경을 확인하세요. 도움이 필요한 항목은 위치와 안내를 열어 볼 수 있습니다.
  • 활동현재 경로, 검사 완료 수와 이름 변경 수를 확인하세요. 필요하면 ‘별도 창으로 보기’로 활동 창을 따로 열어 두세요.
  • 폴더정리할 폴더와 제외 항목, 외장 드라이브를 관리하고 바뀔 이름을 미리 확인하세요.
  • 변경 기록파일 이름·폴더·날짜로 기록을 찾으세요. 한 항목을 선택해 원래 이름을 확인하고 되돌릴 수 있습니다.
  • 설정로그인 실행과 언어·테마를 고르세요. ‘상세 설정’에는 접근 권한, 저장 공간, 진단 안내가 있습니다. ‘사용 설명서 열기…’에서 안내를 다시 확인하세요.

알아두면 좋은 점

궁금한 점.

폴더 선택부터 문제 해결까지,
필요한 방법을 찾아보세요.

macOS에서 앱 실행을 허용하려면?

다운로드 출처를 확인한 뒤 Apple의 앱 실행 허용 안내를 따라 주세요. 앱을 한 번 열고 시스템 설정 → 개인정보 보호 및 보안에서 ‘확인 없이 열기’를 선택하세요. 해당 항목이 없거나 손상 메시지가 나오면 다시 다운로드하거나 지원팀에 문의해 주세요.

정리를 잠시 멈추거나 앱을 종료하려면?

메뉴의 ‘일시 정지’와 ‘재개’로 정리 시점을 조절하세요. 창을 닫으면 백그라운드에서 계속 작업합니다. 작업까지 종료하려면 ‘Jaso NFC 종료’를 선택하고, 다음에 사용할 때는 응용 프로그램 폴더에서 앱을 여세요.

외장 드라이브를 다시 연결하거나 목록에서 제거하려면?

‘폴더’ → ‘드라이브’에서 드라이브를 선택하고 ‘선택한 드라이브 관리…’를 여세요. 자동으로 이어서 정리하거나 연결할 때마다 직접 시작하도록 고를 수 있습니다. 앱 전체의 일시 정지는 유지됩니다.

사용을 마친 드라이브는 상세 창에서 ‘목록에서 제거’를 선택하세요. 연결이 해제된 드라이브도 제거할 수 있습니다. 다른 폴더 변경이 없으면 바로 저장됩니다. 함께 수정 중인 폴더의 미리보기가 필요하면, 미리보기 후 ‘설정 저장’을 눌러 드라이브 제거까지 적용하세요. 저장한 제외 설정은 다시 연결한 뒤에도 유지됩니다. 폴더와 드라이브 설정 안내에서 자세히 확인하세요.

숨김 폴더를 선택하거나 폴더 목록을 비워 두려면?

.ghost-alice, .venv처럼 점으로 시작하는 숨김 폴더는 기본 검사에서 제외합니다. 필요한 숨김 폴더는 ‘폴더’ → ‘선택한 폴더’에 직접 추가하세요. 직접 선택한 폴더 안의 하위 숨김 폴더는 계속 제외합니다.

‘선택한 폴더’ 목록을 모두 비운 상태도 저장할 수 있습니다. 새 폴더를 추가할 때까지 대기하므로, 준비됐을 때 정리할 위치를 선택하세요.

현재 활동과 변경 기록은 어디에서 보나요?

‘활동’에서 현재 경로와 최근 작업, 지금 대기 중인 항목을 확인하세요. 작업이 멈추면 클라우드 보관, 접근 권한 등 기록된 이유를 표시하고, 이후 검사가 성공하면 완료 결과를 표시합니다. 같은 문제로 재시도하면 기존 항목의 횟수와 시각을 갱신합니다.

완료한 이름 변경은 ‘변경 기록’에 한 번 남깁니다. 보관 중인 최근 기록을 검색하고 날짜와 결과로 골라 보세요. 기록을 선택하면 원래 이름과 변경한 이름, 위치를 확인하고 되돌릴 수 있습니다.

깨진 한글 파일명도 복원하나요?

UTF-8 또는 CP949 문자가 Latin-1·Windows-1252로 잘못 읽힌 파일명 중, 원래 한글로 손실 없이 되돌릴 수 있고 복원 근거가 충분한 경우를 복원합니다. ‘파일명 미리보기’에서 결과를 확인하세요. 복원 근거가 충분하지 않거나 여러 해석이 가능한 이름은 현재 이름을 유지합니다. 파일명 복원 안내에서 예시와 처리 범위를 확인하세요.

원래 이름으로 되돌리려면?

‘변경 기록’에서 항목을 선택하고 ‘원래 이름으로 되돌리기’를 누르세요. 확인 안내를 읽고 ‘되돌리기’를 선택한 뒤 완료 메시지를 기다리세요. 파일이 이동했거나 이름이 충돌하면 이유를 표시합니다. 이름 복원 안내를 참고하세요.

클라우드 항목 대기나 저장 공간 부족이 표시되면?

활동에 표시된 경로와 이유를 확인하고 Finder나 동기화 앱에서 연결·다운로드 상태를 살펴보세요. 디스크 여유 공간과 앱 데이터는 ‘설정’ → ‘상세 설정’ → ‘저장 공간 사용량…’에서 확인할 수 있습니다. 필요한 경우 ‘저장공간 설정 열기’로 공간을 확보하세요.

파일 목록은 필요한 정보를 간결하게 저장합니다. 변경 기록과 로그는 정해진 용량 안에서 보관하며 오래된 항목부터 자동으로 정리합니다. 처리 중인 복구에 필요한 기록은 별도로 보관합니다.

어떤 이름을 정리하고 앱은 어떻게 제거하나요?

선택한 폴더 안에서 파일과 폴더의 분리된 한글 이름을 정리하고, 복원 조건에 맞는 깨진 파일명도 복원합니다. ㅎㅏㄴ 같은 호환 자모, 자동 제외 항목과 exFAT 사용 시 주의점은 처리 범위 안내를 확인하세요. 제거할 때는 로그인 실행을 끄고 앱을 종료한 뒤 제거 절차에 따라 응용 프로그램 폴더의 앱을 휴지통으로 옮기세요.
