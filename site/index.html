01단계

설치 파일 열기

다운로드한 .dmg를 열고 Install Jaso NFC.app을 더블클릭한 뒤 ‘설치’를 누르세요.

완료되면 설치 파일을 유지하거나 휴지통으로 옮긴 뒤, 설치 창을 닫고 Finder에서 설치 디스크를 추출하세요.

02단계

변경할 파일 확인하기

메뉴 막대의 Jaso NFC → ‘정리할 폴더…’를 여세요. 정리할 폴더를 고른 뒤 ‘파일명 미리보기’에서 현재 이름과 정리 후 이름을 비교해 보세요.

처음에는 다운로드 폴더부터 시작해 보세요. 필요한 폴더를 더하거나 목록에서 뺄 수 있습니다.

03단계

자동 정리 시작하기

결과를 확인한 뒤 ‘자동 정리 시작’을 누르세요. 선택한 폴더를 정리하고 이후 들어오는 파일도 계속 확인합니다.

메뉴의 ‘상태 보기…’에서 현재 활동과 확인이 필요한 항목을 볼 수 있습니다.

폴더 설정

정리할 곳을 직접 고르세요.

‘정리할 폴더…’에서 목록을 확인하고 폴더를 추가하거나 제거하세요. 기존에 사용 중이라면 저장된 폴더와 제외 설정을 이어서 사용할 수 있습니다.

바뀔 이름을 먼저 확인하세요.

미리보기에서 현재 이름과 정리 후 이름을 나란히 확인할 수 있습니다. 접근할 수 없는 폴더가 표시되면 안내에 따라 권한이나 연결을 확인하세요.

준비되면 ‘자동 정리 시작’을 누르세요. 이후에는 메뉴 막대에서 정리를 잠시 멈추거나 이어갈 수 있습니다.

폴더 접근 권한이 필요하면 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근에 응용 프로그램 폴더의 ‘Jaso NFC’를 추가해 허용하세요. 이후 상태 창에서 ‘작업 다시 시작’을 선택하세요.

매일 쓰는 방법

매일 확인할 일은
메뉴 막대에서.

Jaso NFC가 선택한 폴더를 계속 살펴봅니다. 메뉴 막대에서 처리 상황을 확인하고, 필요한 시간에 맞춰 정리를 멈추거나 이어가세요.

  • 상태 보기현재 활동과 대기 작업을 확인하세요. 문제가 생긴 항목에는 경로와 확인 방법이 표시됩니다.
  • 일시정지·계속 진행다른 작업에 집중할 때 정리를 잠시 미루세요. ‘계속 진행’을 선택하면 대기한 작업을 이어갑니다.
  • 정리할 폴더폴더 목록을 바꾸고 미리보기로 변경할 이름을 확인하세요.
  • 설정로그인할 때 실행하도록 설정하고 언어, 글꼴 테마와 아이콘 애니메이션을 골라 보세요.
  • 창 닫기·앱 종료창을 닫으면 백그라운드에서 계속 정리합니다. 작업까지 마치려면 ‘Jaso NFC 종료’를 선택하세요. 다시 사용할 때는 앱을 열고 ‘작업 시작’을 누르세요.

알아두면 좋은 점

궁금한 점.

폴더 선택부터 문제 해결까지,
필요한 방법을 찾아보세요.

macOS에서 앱 실행을 허용하려면?

다운로드한 파일의 출처를 확인한 뒤 Apple의 앱 실행 허용 안내를 따라 주세요. 앱을 한 번 열어 본 다음 시스템 설정 → 개인정보 보호 및 보안에서 ‘확인 없이 열기’를 선택합니다. 해당 항목이 없거나 손상 메시지가 나오면 다시 다운로드하거나 지원팀에 문의해 주세요.

다른 폴더도 정리하려면?

‘정리할 폴더…’에서 원하는 폴더를 추가하고 미리보기 후 설정을 저장하세요. 이미 설정한 폴더를 다시 확인하려면 상태 창의 ‘전체 감시 영역 다시 확인’을 누르세요. 자세한 순서는 폴더 설정 안내에 있습니다.

클라우드 폴더에 재시도가 표시되면?

상태 창에서 해당 경로와 원인을 확인하고 Finder에서 폴더를 열어 보세요. OneDrive, Google Drive 등 동기화 앱의 로그인과 연결 상태도 확인해 주세요. 연결을 복구한 뒤에는 Jaso NFC가 예약된 시각부터 다시 시도합니다.

어떤 이름을 정리하나요?

설정한 폴더 안에서 분해된 한글 등 NFC 정규화가 필요한 파일명과 폴더 이름을 정리합니다. 직접 입력한 ㅎㅏㄴ 같은 호환 자모는 처리 대상에서 제외됩니다. 앱·사진 보관함 등 자동 제외되는 종류와 직접 제외할 폴더는 처리 범위 안내에서 확인하세요.

이름을 되돌리거나 앱을 제거하려면?

먼저 작업을 중지하고 되돌리기와 제거 안내를 따라 주세요. 변경 기록에 있는 원본 파일을 확인할 수 있으면 이전 이름으로 되돌릴 수 있습니다. 파일을 이동하거나 교체한 경우 복구가 제한될 수 있습니다. exFAT에서는 다른 앱과 동시에 이름을 바꿀 때 덮어쓰기 위험이 있어, 사용 설명서의 처리 한계도 확인해 주세요.

처리 기록은 어디에서 볼 수 있나요?

상태 창의 ‘복구 기록 폴더 열기’로 Mac에 저장된 이름 변경 기록을 확인할 수 있습니다. 문제가 생겼을 때는 ‘진단 정보 복사’로 상태를 전달해 주세요. 공유하기 전에 개인 파일명과 경로를 지워 주세요.
